# 🚍 UrbanSight AI

### AI-Powered Mobile Urban Intelligence Platform

UrbanSight AI is a prototype of a mobile urban intelligence platform designed to help city authorities monitor public transportation, road conditions, traffic, incidents, and fleet operations using AI-powered insights.

> 🚧 Current Status: UI Prototype / Frontend Prototype

---

## 📌 Project Overview

UrbanSight AI provides a centralized command platform for monitoring urban transportation and infrastructure.

The prototype includes dashboards and interfaces for:

- 🚌 Public Transport / Fleet Monitoring
- 🗺️ Live GIS Map
- 🚨 Incident & Alert Management
- 🛣️ Road Intelligence
- 📊 Traffic Analytics
- 🤖 Edge AI Monitoring
- 🔧 Maintenance Management
- 👤 Profile & Settings
- 🧠 AI Copilot

---

## 🎯 Problem Statement

Urban transportation systems generate large amounts of data from buses, cameras, GPS systems, road infrastructure, and traffic networks.

However, this information is often distributed across different systems, making it difficult for authorities to:

- Detect road problems quickly
- Monitor public transport fleets
- Identify traffic problems
- Respond to incidents
- Analyze real-time data
- Coordinate maintenance activities

UrbanSight AI aims to provide a unified intelligence platform for these tasks.

---

## 💡 Proposed Solution

UrbanSight AI combines transportation monitoring, road intelligence, incident detection, and AI-based analysis into a single platform.

The system is designed to eventually process real-time data from:

- Bus GPS
- Vehicle cameras
- Traffic sensors
- Road condition sensors
- Public transportation systems
- Other urban infrastructure

---

## 🖥️ Current Prototype

The current version focuses on the **UI/UX prototype** and frontend implementation.

### Main Modules

| Module | Description |
|---|---|
| Command Center | Central urban intelligence dashboard |
| Live GIS Map | Map-based incident and fleet visualization |
| Edge AI Monitor | AI camera monitoring interface |
| Fleet Monitor | Public transport fleet monitoring |
| Road Intelligence | Road condition and pothole monitoring |
| Traffic Analytics | Traffic and congestion analysis |
| Alerts | Critical incident and alert management |
| Maintenance | Maintenance task management |
| AI Copilot | AI-assisted urban operations |
| Profile | User and system settings |
